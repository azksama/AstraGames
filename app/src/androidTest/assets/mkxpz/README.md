# Original synthetic RGSS fixtures

Generated by `scripts/mkxpz/generate-fixtures.py`. All script and PCM content is
original and dedicated to the public domain under CC0-1.0. No RTP, commercial
game, editor DLL, or MTool material is included. DLL names in Game.ini are format
identifiers only; MKXP-Z supplies the RGSS implementation.

XP, VX and Ace archives contain the same probe under their native Scripts
extension. The probe exercises Ruby Marshal, Table, Sprite, Bitmap, font drawing,
Graphics, Input and Audio bindings. Right changes state, A/Enter atomically saves,
B/Escape exits. Relaunch loads the saved state. `astra-proof.json` is written by
the real Ruby VM after rendering; tests must also inspect a screenshot.

This is not a full game compatibility corpus: no RTP, Win32API plugins, encrypted
archives, large maps, video or MIDI coverage is claimed.
