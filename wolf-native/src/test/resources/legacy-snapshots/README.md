# Authored legacy snapshot fixtures

These small states belong to Astra's own AWNS format. They contain no commercial game files or saves.
They are frozen input to the compatibility tests, not generated by the current reader during a test.

`v2-beta14.snap` was generated with the unmodified published beta14 writer at commit
`32d055d0ecd253c8bd94abb36df420feb4de7913` (only its object name was changed to isolate it).
It holds number 42, the string `ancienne sauvegarde`, coordinates (2,2), tick17 and a text picture.
Its SHA256 is `2cbebf5eea4b163bfcd15fc77cb50e0c491f47992d64c5de3eb60ff9af263c1e`.

The v15–v19 fixtures were captured before the subsequent motion/text-timing layout changes,
from the v19 compiled core SHA256 `52dae195ae67aa4d7edcfa510233cc29f111a6dacc24630bc79bc1411b380045`.
The empty states retain the fixture's original hero. Earlier version suffixes remove only the
empty optional map/database overlay flags, according to their versioned layout. The v18 picture
record was checked against an independently written fixed v18 record before removing the v19
font capture count. Both picture states have an empty captured font set, while SysS62 is already
`Spectral ExtraLight`: older rasterized text must keep the initial font.
